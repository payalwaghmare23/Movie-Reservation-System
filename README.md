# Movie Reservation System

A Python-based application developed to manage movie reservations and related operations.

## Project Overview

The Movie Reservation System is designed to handle different aspects of a movie booking process, including user management, movie information, theatre details, booking, and payment.

## Features

- User management
- Movie management
- Theatre management
- Movie booking
- Payment handling
- Reservation management

## Technologies Used

- Python

## Project Structure

```text
Movie_Reservation/
├── 1main.py
├── booking.py
├── movies.py
├── payment.py
├── theatres.py
├── users.py
└── Movie-Reservation-System_final.pptx
```

## File Description

### 1main.py

Main file used to run the application.

### users.py

Handles user-related operations.

### movies.py

Handles movie-related information and operations.

### theatres.py

Handles theatre-related information and operations.

### booking.py

Handles movie booking and reservation operations.

### payment.py

Handles payment-related operations.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/payalwaghmare23/Movie-Reservation-System.git
```

### 2. Navigate to the project folder

```bash
cd Movie-Reservation-System/Movie_Reservation
```

### 3. Run the application

```bash
python 1main.py
```
